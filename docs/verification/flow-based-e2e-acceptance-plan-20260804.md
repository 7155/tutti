# Tutti Windows P0/P1 主流程验收编排

本文件将 200 条核心用例作为明细库，验收时按真实用户主流程串联执行，不按单条用例孤立点击。每条主流程需要记录：起始状态、关键操作、结果回传、截图、日志证据，以及失败/权限/窗口管理边界。

## 主流程顺序

1. 启动、登录、Agent 主窗口
2. 新建会话并完成一次 Agent 任务
3. 文件窗口读写/选择文件
4. 网页窗口访问网页并回传结果
5. 终端窗口执行命令
6. 应用中心安装并打开应用
7. Tutti @互通完成一次跨 Agent 协作
8. 任务中心查看任务状态和结果
9. 失败、权限、窗口管理边界场景

## 流程验收规则

### FLOW-01 启动、登录、Agent 主窗口

- 启动 dev renderer 和 tuttid。
- 确认登录用户、Agent 主窗口、会话列表、输入区、运行权限控件和 Dock 均可见。
- 边界：未登录/登录态失效、模型列表为空、主窗口重复打开、窗口最小化后恢复。
- 证据：启动截图、登录/Provider 状态、tuttid 启动日志。

### FLOW-02 新建会话并完成一次 Agent 任务

- 从 Agent 主窗口新建会话。
- 提交一个只读任务，等待工具调用完成，并确认结果回到当前会话。
- 继续验证会话状态、任务结果、模型/权限展示和重新发送。
- 边界：命令执行失败、超时、取消、权限询问、Windows UAC 辅助进程取消。
- 已验证：Windows 沙箱修复后的真实会话使用 `sandbox = "unelevated"`，只读命令返回 `tutti-sandbox-e2e-ok`。

### FLOW-03 文件窗口读写/选择文件

- 打开文件窗口，进入 Downloads/个人版工作区。
- 选择测试文件，查看详情并回传给 Agent。
- 在临时测试目录完成一次安全写入，再读取并确认内容。
- 边界：中文路径、空目录、超长路径、无权限目录、取消选择、窗口关闭后恢复。

### FLOW-04 网页窗口访问网页并回传结果

- 打开网页窗口，访问 `https://example.com` 等稳定测试页。
- 读取标题/正文摘要并回传当前 Agent 会话。
- 边界：无效地址、加载失败、网络中断、刷新、多个标签页、关闭后重开。

### FLOW-05 终端窗口执行命令

- 打开 Tutti 内置终端，执行只读 `cmd.exe` 命令。
- 验证 cwd、输出、CRLF、窗口尺寸和历史记录。
- 边界：命令不存在、非零退出码、超时、终端关闭/恢复、子进程清理。
- 不自动操作独立 Windows Terminal/PowerShell/CMD 窗口；只验收 Tutti 内置终端。

### FLOW-06 应用中心安装并打开应用

- 打开应用中心，选择目标应用，安装并等待健康检查。
- 从应用中心打开应用，验证窗口、端口/health 状态和返回 Agent 流程。
- 边界：下载失败、安装失败、健康检查失败、重复安装、应用窗口关闭/重开。
- 安装或运行新下载软件属于需要用户确认的高风险 UI 动作；没有确认时记录 BLOCKED，不代替用户确认。

### FLOW-07 Tutti @互通跨 Agent 协作

- 在主 Agent 会话中 @ 目标 Agent。
- 提交一个小型只读协作任务，等待目标 Agent 完成并把结果回传主会话。
- 验证协作者状态、结果归属、原会话上下文和失败重试。
- 边界：目标不可用、协作超时、重复 @、取消、结果回传失败。

### FLOW-08 任务中心查看状态和结果

- 从主流程打开任务中心。
- 查看任务从待开始、执行中到已完成的状态变化及结果详情。
- 与 Agent 会话结果交叉核对。
- 边界：失败、取消、空列表、筛选切换、任务详情窗口关闭/恢复。

### FLOW-09 失败、权限、窗口管理边界

- 汇总前 8 条流程中产生的可复现失败路径。
- 单独验证权限模式切换、UAC/Windows 安全桌面不可交互时的提示和恢复路径。
- 验证窗口打开、关闭、最小化、最大化、重复打开、遮挡和恢复焦点。
- 对每个边界记录 PASS、FAIL 或 BLOCKED，不能把“未执行”标为 PASS。
